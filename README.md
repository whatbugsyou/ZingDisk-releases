# ZingDisk

Disk space analyzer for macOS and Windows — see what's taking up your disk in one fast, visual pass.

## Download

- **macOS**: [Mac App Store](https://apps.apple.com/us/search?term=ZingDisk&platform=mac)
- **Windows**: supported since v1.6.0 — see the [latest release](https://github.com/whatbugsyou/ZingDisk-releases/releases/latest)

All versions: [Releases](https://github.com/whatbugsyou/ZingDisk-releases/releases).

## What it does

- Scans fast (Rust, three speed modes) and shows your whole disk as an interactive sunburst chart.
- Drill in without losing your place: layer ruler, breadcrumbs, rectangle view, built-in dark themes.
- Search, filter and preview files right in the list; optional AI analysis explains what is safe to remove.
