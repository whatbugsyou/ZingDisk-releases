**洞察磁盘。一目了然。** —— ZingDisk 1.6.0：新增 Windows 支持，界面焕新，导航更顺滑。

## 更新内容

### Windows 支持（首个 Windows 版本）

ZingDisk 现在不止跑在 macOS 上，也支持 Windows。

- 整个磁盘都能扫完整：超长文件名、嵌套远超常见路径长度的目录都不会被跳过、也不会悄悄丢掉。
- 移到回收站、悬停预览、「在资源管理器中显示」都与资源管理器的行为一致，删掉的东西随时能恢复。
- 自绘标题栏（最小化 / 最大化 / 关闭）保留 Windows 11 贴靠布局弹层，观感与 macOS 一致；整条标题栏都能拖动窗口。
- 共享的文件只计一次并标出「共享」；大小与数量按 Windows 用户的习惯单位显示。

### 界面焕新与主题

- 新默认外观：顶栏与绘图区同色，整体更统一。
- 内置两套深色主题——**One Dark Pro**（默认）与 **macOS Classic Dark**，设置页新增「外观」分区即可切换，选中即生效并记住选择。

### 面包屑跟随层级刻度

按住并拖动层刻度条，面包屑实时跟随：高亮与横向滚动都跟着你指向的层或目录走。拖到祖先槽即预览那个目录，拖到布局层即看那一层；点击高亮项回到当前目录。

### 旭日图更干净、动画更轻

楔形之间的分隔缝在任意尺寸下都画得干净，动画开销更低——观感更整洁，滑动更顺。

### 修复

- 钻入目录不再换色——列表标题、面包屑与主图现在一致。
- 更新提示不再出现两个「v」前缀。
- 进入 L2 层面包屑会滚动到末尾，窗口缩放后会重新贴边。
- Windows：整条标题栏都能拖动窗口；超长路径前缀不再出现在界面或「复制路径」里；文件与目录数量与资源管理器一致。
